# GameOne - Event Management System

GameOne is a modern, production-ready event management platform built for
handling event registration, payments, user management, and internationalization
with enterprise-grade security and performance.

## Core Features

- **Event Management** - Create, manage, and publish events with comprehensive
  registration workflows
- **User Registration** - Seamless event registration with approval workflows,
  group registrations, and waiting lists
- **Payment Processing** - QR codes, bank transfers, and payment tracking with
  Slovak banking integration
- **User Management** - Role-based access control with granular permissions
  system
- **Internationalization** - Czech and English language support with extensible
  translation system
- **Communication** - Automated email notifications using Resend with
  professional templates

## Target Users

- Event organizers and managers
- Participants registering for events
- Administrators managing the platform
- Payment processors handling financial transactions

## Key Business Logic

- Events have capacity limits with automatic waiting list management
- Registration requires approval workflow for certain event types
- Payment integration with Slovak banking system (variable symbols, QR codes)
- Group registrations with friend management
- Comprehensive audit logging for all user actions
- Video clip sharing system for event content
