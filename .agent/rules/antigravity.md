## 🚨 CRITICAL PROJECT RULES (NON-NEGOTIABLE)

### 1. File Size Limits

- **ABSOLUTE LIMIT**: 300 lines per file.
- **WARNING ZONE**: 200 lines. Plan refactoring immediately.
- **ACTION**: If a file exceeds these limits, I MUST break it down into
  sub-components, hooks, or utilities.

### 2. Type System (STRICT)

- **NO INLINE TYPES** for components.
- **SEPARATE FILES**: All types must be in a corresponding `.types.ts` file
  (e.g., `MyComponent.types.ts`).
- **Interfaces vs Types**:
  - Use `interface` for props, API contracts, and extendable shapes.
  - Use `type` for unions, primitives, and complex intersections.

### 3. Folder Structure

- **UI Components**: `src/components/ui/` (Simple, reusable, <100 lines).
- **Feature Components**: `src/components/features/` (Complex, domain-specific).
- **Global Types**: `src/types/`.
- **Hooks**: `src/hooks/`.
